# Active Directory Home Lab

## Overview

This project documents the deployment of a Windows Server 2025 Active Directory environment in Oracle VirtualBox.

The objective of this lab is to build a realistic enterprise network that can be used to practice Windows administration, Active Directory management, Group Policy, incident response, and security monitoring.

---

## Lab Environment

| Component | Technology |
|-----------|------------|
| Hypervisor | Oracle VirtualBox |
| Domain Controller | Windows Server 2025 |
| Client | Windows 11 Pro |
| Security Workstation | Kali Linux |
| Domain | cfloydtech.local |
